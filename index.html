使用方法
  1. 右上の設定ボタンからイベント名、イベント期間、限定ドロップ刀剣を登録する
  2. カウンターでドロップ刀剣をカウント
  3. イベントが終了したらドロップ記録タブの「コピー」ボタンから表形式でドロップ記録を保存
  4. リセットボタンを押す
💡 便利な機能
  • リストにない刀剣は検索からカウントすると最下部に表示されます
  • 過去のカウント履歴（Log）は、右上の設定（⚙）から新着順で確認できます。
  • 複数端末でリアルタイムにデータを同期したい場合は、設定内から「スプレッドシート連携」を行うと便利です。
🛡 安全性について
当ツールに入力された情報やGASウェブアプリのURL、Googleアカウントなどの個人情報が外部へ共有・送信されることは一切ありません。データはすべてご自身のブラウザまたはスプレッドシート内のみで安全に管理されます。

スプレッドシート連携

各自のGASウェブアプリURL（末尾が /exec のもの）を貼り付けて保存してください。

連携方法 スプレッドシートのコピーを作成
・ 初回立ち上げ設定 ・
  1. コピーしたシートの共有設定を変更する タップで表示

    一般的なアクセスの設定を「リンクを知っている全員」「編集者」に変更する

  2. 上のメニューから「拡張機能」→「Apps Script」を開く
  3. トリガーを追加する タップで表示
    1. 左メニューの時計マーク「トリガー」を押す
    2. 右下の「＋ トリガーを追加」を押す
    3. 実行する関数を「onEditInstalled」、イベントの種類を「編集時」にして保存を押す
    4. Googleの警告画面が出たら「詳細」→「刀剣カウンターに移動」→「許可」の順に進む
  4. GASウェブアプリURLを取得する タップで表示
    1. 右上の青い「デプロイ」→「新しいデプロイ」を押す
    2. 歯車マークが「ウェブアプリ」なのを確認
    3. 次のユーザーとして実行を「自分」、アクセスできるユーザーを「全員」に変更してデプロイを押す
    4. 発行された「ウェブアプリURL」をコピー
